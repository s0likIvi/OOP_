# Лабораторні роботи

У цьому розділі зібрані мої **лабораторні роботи** з об'єктно-орієнтованого програмування. Тут можна переглянути їхні теми та поточний статус.

> Кожна робота допомагає закріпити знання на практиці й навчитися створювати програми.

## Мета

Під час виконання завдань я буду:

- вивчати основи *об'єктно-орієнтованого програмування*;
- писати та перевіряти код;
- поступово доповнювати цю таблицю.

**Статус «Не розпочато»** означає, що робота ще очікує на виконання.
