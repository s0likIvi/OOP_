### Як працювати з репозиторієм та VS studio code 
Щоб почати роботу з репозиторієм, потрібно виконати наступні кроки: 
- відкрити репозиотрій у VS studio code 
- створити необхідні файли та папки для виконання завдань
- внести зміни у файли та зберегти їх натиснувши Comit
- відкрити GitHub та перевірити результат
